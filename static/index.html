4-Qubit ZZ Feature Map & Quantum Circuit

The quantum model maps classical 4D continuous data \(x \in \mathbb{R}^4\) into a 4-qubit Hilbert state space \(\mathcal{H} \approx \mathbb{C}^{16}\) using a second-order Pauli Expansion Feature Map (\(\text{ZZFeatureMap}\)) with 2 repetitions and linear entanglement.

Mathematical Feature Map Encoding

\(|\Phi(x)\rangle = U_{\Phi(x)} |0\rangle^{\otimes 4} = \left( \prod_{(i,j) \in E} U_{ZZ}(x_i, x_j) \prod_{i=1}^4 U_Z(x_i) H^{\otimes 4} \right)^2 |0\rangle^{\otimes 4}\)
Where: \(U_Z(x_i) = \exp\left(i x_i Z_i\right)\) and \(U_{ZZ}(x_i, x_j) = \exp\left(i (\pi - x_i)(\pi - x_j) Z_i Z_j\right)\)

Abstract

This project investigates binary classification of breast masses as benign or malignant using a hybrid quantum-classical machine-learning pipeline. The Wisconsin Diagnostic Breast Cancer dataset contains 569 observations and 30 real-valued features derived from digitized fine-needle aspiration images. A classical radial-basis-function support vector machine is used as the baseline. The proposed quantum model reduces the standardized data to four principal components, maps these values into a four-qubit ZZ feature map, evaluates pairwise state fidelity, and supplies the resulting quantum kernel to a Quantum Support Vector Classifier. Both models use the same split and preprocessing pipeline to maintain a fair comparison.

1. Introduction

Machine learning can identify statistical patterns in measured biomedical features, but a model's output is not the same as a medical diagnosis. Quantum machine learning is explored through a quantum kernel: classical data are encoded into quantum states, similarity is estimated from state overlap, and a conventional support vector machine performs the final optimization.
